## Возможности

- Авторизация через логин и пароль БАРС  
- Расписание занятий по дням и неделям  
- Оценки за семестр + детализация контрольных, тестов, лабораторных  
- Итоговые баллы, вес заданий, даты  
- Чистый современный интерфейс  
- Светлая и тёмная темы  
- Адаптивный дизайн  

## Технологии

- **UI** — SwiftUI (iOS 16+)  
- **Архитектура** — MVVM  
- **Сеть** — URLSession + async/await  
- **JSON** — Codable  
- **Backend** — FastAPI + MongoDB
